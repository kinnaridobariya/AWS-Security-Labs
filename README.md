# AWS-Security-Labs
Hands-on experience with AWS services like CloudTrail and CloudWatch to monitor and secure cloud environments

This repository contains lab exercises focused on various AWS services. Each lab is designed to help you understand, configure, and work with different AWS offerings, including EC2, S3, VPC, Lambda, and more.
